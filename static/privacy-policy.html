Privacy Policy

Last updated: September 23, 2026

1. Stateless BYOK Architecture

Linkbot is a completely stateless, "Bring Your Own Key" (BYOK) application. We do not use user accounts, and we do not operate a backend database. Your data remains yours.

2. API Keys

Any Gemini or Serper API keys you provide are used strictly in-memory during a single analysis request. They are never stored, logged, or persisted to our servers, nor are they saved in your browser's local storage.

3. Uploaded Data

Resumes (PDFs), GitHub URLs, and pasted bio texts are processed transiently to generate your structured profile. Once the server returns the response to your browser, all uploaded and extracted data is immediately discarded. Nothing is retained.

4. Third-Party Services

To provide its core functionality, Linkbot passes your transient data to the following third-party APIs during an active request:

  • Google Gemini API: For synthesizing your profile and assigning candidate actions.
  • Serper API: For executing live Google searches to find LinkedIn candidates.
  • GitHub Public REST API: For fetching public repository and bio data (if a GitHub URL is provided).
